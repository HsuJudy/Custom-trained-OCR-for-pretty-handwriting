# Keyboard Shortcuts Reference

## Efficient Labeling Tool Shortcuts

### Navigation
- **Enter**: Save current line and move to next
- **Space**: Skip current line
- **Backspace**: Go to previous line
- **Tab**: Cycle through auto-suggestions

### Quick Actions
- **Ctrl+1**: Empty line
- **Ctrl+2**: Date placeholder `[DATE]`
- **Ctrl+3**: Signature placeholder `[SIGNATURE]`
- **Ctrl+4**: Page number placeholder `[PAGE]`
- **Ctrl+5**: Common word 1
- **Ctrl+6**: Common word 2
- **Ctrl+7**: Common word 3
- **Ctrl+8**: Common word 4
- **Ctrl+9**: Common word 5

### General
- **Ctrl+S**: Save current line
- **Esc**: Clear text input
- **Double-click suggestion**: Use selected suggestion

## Web Interface Shortcuts

### Cropping
- **Click and drag**: Select crop area
- **Click**: Start new crop (clears previous)

### Labeling
- **Type**: Enter label text
- **Enter**: Save crop and label
- **Tab**: Focus next field

## Productivity Tips

### Speed Optimization
1. **Learn the shortcuts**: Practice Ctrl+1-9 for common actions
2. **Use auto-suggestions**: Tab through suggestions instead of typing
3. **Skip unclear text**: Don't waste time on illegible content
4. **Batch similar items**: Group similar characters/words together
5. **Take regular breaks**: Labeling is mentally intensive

### Quality Tips
1. **Be consistent**: Use the same format for similar items
2. **Use placeholders**: [DATE], [SIGNATURE] for repeated elements
3. **Check confidence**: Lower confidence for uncertain transcriptions
4. **Review periodically**: Go back and check your work

### Expected Speed
- **Beginner**: 10-20 items/minute
- **Experienced**: 30-50 items/minute
- **With shortcuts**: 50-100 items/minute
